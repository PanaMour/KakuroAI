# KakuroAI – Adaptive Kakuro Puzzle Game with Reinforcement Learning

KakuroAI is an intelligent puzzle game built in Unity that leverages reinforcement learning to dynamically adapt the difficulty of Kakuro puzzles based on player performance. The system uses Unity ML-Agents for training a difficulty adjustment agent, a procedural puzzle generator for creating valid Kakuro grids with varying complexity, and a custom player tracking system that monitors solve time, mistakes, and hint usage. As users solve puzzles, KakuroAI continuously evaluates their performance and modifies future puzzles to provide a personalized, balanced challenge. The game includes a clean and interactive UI with real-time feedback, hint support, and difficulty progression tailored to each player’s skill level.
